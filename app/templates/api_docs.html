Paginazione

Tutti gli endpoint di lista restituiscono 25 risultati per pagina. Usa il parametro page per navigare.

Per scaricare tutti i risultati in un'unica risposta, senza paginazione, imposta per_page=all.

Struttura risposta
{
  "page": 1,
  "per_page": 25,
  "total": 1162,
  "total_pages": 47,
  "items": [ ... ]
}
Scaricare tutto (senza paginazione)
GET /api/v1/people?per_page=all
Persone
GET /api/v1/people

Lista paginata delle persone citate nel carteggio.

ParametroTipoDescrizione
searchstringRicerca sul nome
sexm | fFiltra per sesso
birth_fromintegerAnno di nascita minimo
birth_tointegerAnno di nascita massimo
pageintegerPagina (default: 1)
per_pageallSe all, restituisce tutti i risultati senza paginazione
Esempio richiesta
GET /api/v1/people?search=Canneti&sex=m
Risposta
{
  "page": 1,
  "per_page": 25,
  "total": 1,
  "total_pages": 1,
  "items": [ { "id": "DLCL_CF_PC0001", ... } ]
}

Luoghi
GET /api/v1/places

Lista paginata dei luoghi.

ParametroTipoDescrizione
searchstringRicerca sul nome
typestringTipo (es. settlement)
countryISO 3166Nazione (es. IT)
pageintegerPagina (default: 1)
per_pageallSe all, restituisce tutti i risultati senza paginazione
Esempio richiesta
GET /api/v1/places?type=settlement&country=IT
Risposta
{
  "page": 1, "per_page": 25,
  "total": 111, "total_pages": 5,
  "items": [ { "id": "DLCL_CF_L0002", ... } ]

Specifica OpenAPI

La specifica completa è disponibile in formato OpenAPI 3.1 (YAML). Puoi usarla per esplorare l'API interattivamente, generare client automatici in qualsiasi linguaggio, o integrare i dati in portali come Sampo-UI.

openapi.yaml
Importa in Swagger Editor
File → Import URL:
https://digiletclass.unibo.it
  /api/openapi.yaml
